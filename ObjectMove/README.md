# 移动物体（ObjectMove v0.8.1）

## 功能

- **移动方式与星露谷 Move It 相同**：
  1. 按住 **Alt** 并**鼠标左键点击**物体，将其拿起（提示常驻显示）；
  2. 松开 Alt，光标处出现**绿色幽灵框**（跟随鼠标，显示物体名）；
  3. 移动光标到目标位置，**点击鼠标左键**放下，物体落在框的位置；
  3. 按 **Esc** 可取消（物体放回原位）。
- 支持箱子、家具、加工机等**可摆放 gimmick**（扫描白名单，建筑/场景
  部件不会出现在列表），以及动物（家畜/宠物）。
- 屏幕↔世界坐标自动校准：横/纵独立缩放（游戏世界 X/Y 各向异性），
  拿起物体时累积可靠样本，最小二乘解出 zx/zy、Y 方向与玩家屏幕偏移；
  校准值自动写回 `objectmove.txt`；切换相机倍率时自动重新校准。
- 物体扫描覆盖全部场景 gimmick（箱子/家具/加工机/作物/牧草等），
  启动日志记录一次类型清单。

## 操作

| 操作 | 功能 |
| --- | --- |
| Alt + 鼠标左键 | 拿起光标下的物体 |
| 鼠标左键（松开 Alt） | 在光标位置放下 |
| Esc | 取消（放回原位） |
| F10 | 光标坐标探测（定位游戏自身的鼠标→世界坐标，用于精确放置） |

## 校准

校准由 Mod 自动进行（需在不同位置点击至少 3 个物体，数值异常会自动
拒绝）。也可以手动微调 `objectmove.txt` 里的 `CalibZoomX/Y`、
`CalibOX/OY`，保存后实时生效（无需重启）。

## 安装

1. 关闭游戏；
2. 将 `ObjectMove_v0.2.0` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 通过 `VillageModLoader.exe` 启动游戏。

## 卸载

删除 `Mods\ObjectMove_v0.2.0` 文件夹即可。

## 配置（自动维护）

`objectmove.txt` 由 Mod 自动写入校准值：

```ini
CalibZoom=0.9000
CalibYFlip=1
```

首次拿起物体后自动校准；多次拿起会持续修正。数值异常时可删除该文件
重新校准。
