# Village in the Shade - 时间冻结（TimeFreeze v0.1.0）

> [English](README_EN.md)

## 功能

- 按 **F5** 冻结 / 恢复主世界时间。
- 仅在深夜（游戏显示 00:00–05:59）可用，其他时段按 F5 提示
  "当前时段不可用，请深夜再试"（显示 1 秒）。
- 冻结时右下角常驻显示 `TimeFreeze ON`，再按 F5 恢复时消失。

> 注意：过剧情或时间限制任务时请勿冻结。

## 安装

1. 关闭游戏；
2. 将 `TimeFreeze_v0.1.0` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 通过 `VillageModLoader.exe` 启动游戏（设为 Steam 启动项）。

> 只适配相同游戏版本（village.exe 18,108,416 字节）。游戏更新后本 Mod 可能失效。

## 卸载

删除 `Mods\TimeFreeze_v0.1.0` 文件夹即可。

## 兼容性

- 不修改任何指令字节，可与 Village QoL Mod（含其午夜减速）共存，无冲突。
