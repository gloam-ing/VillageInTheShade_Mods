# Village in the Shade - Time Freeze (TimeFreeze v0.1.0)

> [中文版](README.md)

## Features

- Press **F5** to freeze / resume the world clock.
- Only available at night (in-game 00:00–05:59). Pressing F5 at other times
  shows "not available at this time, try again at night" (for 1 second).
- While frozen, `TimeFreeze ON` is shown in the bottom-right corner; it
  disappears when you resume.

> Note: do not freeze during story events or time-limited quests.

## Installation

1. Close the game.
2. Put the `TimeFreeze` folder into the `Mods` folder in the game root.
3. Launch the game via `VillageModLoader.exe` (set it as a Steam launch option).

> Only compatible with the same game version (village.exe 18,108,416 bytes).
> Mods may break after game updates.

## Uninstallation

Delete the `Mods\TimeFreeze` folder.

## Compatibility

- Does not modify any code bytes; coexists with the Village QoL Mod
  (including its midnight time slowdown) without conflicts.
