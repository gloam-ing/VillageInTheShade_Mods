## 安装

本 Mod 基于 VillageModLoader 注入体系，与其它 Mod（相机、备用版 QoL 等）共存，
互不干扰、不修改游戏文件。

1. 关闭游戏；
2. 根目录新建 `Mods` 文件夹；
3. 将 `VillageModLoader.exe` 放入 `Mods` 文件夹；
4. 将整个 `TeleportMod_v2.1.2` 文件夹放入 `Mods` 文件夹；
5. 按下方"启动方式"运行游戏。

> 默认使用 `teleport.dll`（键盘 + 手柄）。只玩键盘的玩家可以把 `teleport.dll` 备份到`Mods` 外文件夹或者删除（二选一，不要两个同时放在 Mods 里，加载器会全部注入导致冲突）。

> 只适配相同游戏版本（village.exe 18,108,416 字节）。游戏更新后本 Mod 可能失效。

### 升级 / 保留解锁记录

新版模板与旧版内容不同（目的地列表、默认键位等）。升级时只保留
自己的解锁记录，其余全部使用新版模板：

1. 使用新版模板 `teleport.txt`（随发布包提供）；
2. 打开旧的 `teleport.txt`，把其中 `Unlock=` 开头的解锁记录行（文档末尾），
   全部复制到新版 `teleport.txt` 的 `#以下内容自动写入` 下面；
3. 旧版改过的键位如需保留，可自行在新版里修改。

## 卸载

直接删除游戏根目录 `Mods\TeleportMod_v2.1.2` 文件夹即可。

## 启动方式

本 Mod 通过 `VillageModLoader.exe` 注入。推荐在 Steam 里设置启动项，自动完成注入：

### 方式一：Steam 启动项（推荐）

1. Steam 库 → 右键《Village in the Shade》→ 属性 → 启动选项；
2. 填入下面内容（把路径换成你自己的游戏根目录）：

   ```
   "你的游戏根目录\Mods\VillageModLoader.exe" & %command%
   ```

   例如：

   ```
   "D:\Steam\steamapps\common\Village in the Shade\Mods\VillageModLoader.exe" & %command%
   ```

3. 之后直接从 Steam 启动游戏即可，Mod 会自动注入，无需每次手动运行加载器。

### 方式二：手动运行加载器

每次启动游戏前，先双击 `Mods\VillageModLoader.exe`（保持窗口运行），
再从 Steam 启动游戏。

> 忘记运行加载器时，Mod 不会生效（进入存档后按 F6 无反应）。

## 使用

| 操作 | 键盘 | 手柄 |
|------|------|------|
| 打开 / 关闭菜单 | F6 | LB |
| 设置页 | 、 | A |
| 选择 | PgUp / PgDn | ← / → |
| 翻页 | [ / ] | ↓ |
| 传送 | Enter | RB |
| 关闭菜单 | Esc | LB（再按一次） |
| 显示 / 隐藏玩家坐标 | F7 | — |

- 传送点必须亲自到访过附近（300 单位）才会解锁；
- 提示：传送是直接改坐标，建议同地图内传送；跨地图传送可能位置异常。

## 文件

| 文件 | 说明 |
|------|------|
| `teleport.dll` | 传送 Mod 本体（键盘 + 手柄） |
| `teleport_kb_only.dll` | 纯键盘版（替换 `teleport.dll` 使用，二选一） |
| `teleport.txt` | 传送配置与目的地列表（更新版本时不会被覆盖） |
| `teleport.log` | 运行日志（每次启动自动清空） |

## 警告
