# Village in the Shade - Birthday Reminder (BirthdayReminder v0.1.0)

> [中文版](README.md)

## Features

- Shows today's birthday villager in the top-right corner of the screen using
  the game's own font (Resource Han Rounded TC), white 45px, e.g.
  "Today's Birthday: Kimosuke".
- Automatically hides when nobody has a birthday; refreshes on a new day.

## Installation

1. Close the game.
2. Put the `BirthdayReminder` folder into the `Mods` folder in the game root.
3. Launch the game via `VillageModLoader.exe` (set it as a Steam launch option).

## Uninstallation

Delete the `Mods\BirthdayReminder` folder.

## Files

| File | Description |
|------|-------------|
| `birthdayreminder.dll` | The mod itself |
| `ResourceHanRoundedTC-Regular.ttf` | The game's font (loaded privately, not installed to the system) |
| `birthdayreminder.log` | Runtime log (auto-generated in game) |
