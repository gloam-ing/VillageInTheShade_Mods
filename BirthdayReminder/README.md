# Village in the Shade - 生日提醒（BirthdayReminder v0.1.0）

## 功能

- 每天在屏幕右上角显示今日过生日的村民，使用游戏同款字体
  （Resource Han Rounded TC），白色 45 号，例如"今日生日：木助"。
- 当天无人生日时自动隐藏；跨日自动刷新。

## 安装

1. 关闭游戏；
2. 将 `BirthdayReminder_v0.1.0` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 通过 `VillageModLoader.exe` 启动游戏（设为 Steam 启动项）。

## 卸载

删除 `Mods\BirthdayReminder_v0.1.0` 文件夹即可。

## 文件

| 文件 | 说明 |
|------|------|
| `birthdayreminder.dll` | Mod 本体 |
| `ResourceHanRoundedTC-Regular.ttf` | 游戏同款字体（私有加载，不安装到系统） |
| `birthdayreminder.log` | 运行日志（游戏内自动生成） |
