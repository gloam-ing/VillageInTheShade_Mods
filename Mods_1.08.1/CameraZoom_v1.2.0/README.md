# 相机视角 Mod（Camera Zoom Mod v1.2.0）



## 功能

- 调整相机三档缩放倍率（近 / 中 / 远）；
- 原版倍率为 1.2 / 1.35 / 1.5，本 Mod 默认 0.6 / 0.9 / 1.2；
- 注意：这是"放大倍率"，**值越小镜头越远、看到的范围越大**；
  0.4 太远会导致远景渲染断层，出现断层时把数值调大。

## 安装

1. 关闭游戏；
2. 将整个 `CameraZoom_v1.2.0` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接自动加载）。

> 倍率表为运行时动态定位，游戏更新后通常仍能自动适配。

## 卸载

直接删除游戏根目录 `Mods\CameraZoom_v1.2.0` 文件夹即可。

## 文件

| 文件 | 说明 |
|------|------|
| `camerazoom.dll` | 相机 Mod 本体 |
| `camera_zoom.txt` | 倍率与补丁配置 |

## 警告

- 倍率过小可能导致远景渲染断层，请保持合理数值。
