# 狩猎一击必杀（HuntOneShot v0.2.0）



## 功能

- 可狩猎动物（松鼠、狸猫、鼬鼠、兔子、狐狸、绿雉、野猪、鹿、熊）
  一枪即可狩猎成功，不需要再打多枪；
- 不影响掉落物与狩猎结算，动物仍会正常逃跑/消失。

## 匹配方式与限制

- 采用**初始命中次数白名单**（按实例 +0x10 高 32 位的初始值，而非当前值）：
  `{30, 40, 50, 150, 200, 500}`（松鼠 30 / 狸猫·鼬鼠·兔子 40 /
  狐狸·绿雉 50 / 野猪 150 / 鹿 200 / 熊 500）；
- 动物实例中不存在可读取的物种名称/ID，只能按数值区分；
- 已知限制：野猪之主/鹿之主与普通版同为 150/200，会被一并一击必杀；
  熊之主（600）不在白名单，保留挑战。

## 安装

1. 关闭游戏；
2. 将 `HuntOneShot_v0.2.0` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

> 只适配相同游戏版本（village.exe 18,105,864 字节）。游戏更新后本 Mod 可能失效。

## 卸载

删除 `Mods\HuntOneShot_v0.2.0` 文件夹即可。
