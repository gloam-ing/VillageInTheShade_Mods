# 自动化生产（Automate v0.5.4）



## 功能

- 星露谷式自动化：机器与箱子通过相邻关系泛洪连接成组，自动从连接组的箱子取原料装料，加工完成后将成品放入连接组的箱子；
- 机器启动顺序以连接组的箱子为起点逐层外扩（水流式），离箱子最近的机器优先装料；
- 支持全部加工机器：腌菜桶、牛奶加工机、美乃滋加工机、酿造桶、熟成桶、干燥机、研磨机、榨油机、熔炉、木炭窑、织布机、堆肥桶、烟熏机、蜂箱、蚕箱（含 1/2 级变体）；
- 配方表按游戏数据自动生成并写入 `automate.txt`；
- 地址自动解析：游戏更新后签名失效时自动停用并写入日志，不会崩溃。

## 安装

1. 关闭游戏；
2. 将 `Automate_v0.5.4` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

> 只适配相同游戏版本（village.exe 18,105,864 字节）。游戏更新后本 Mod 可能失效。

## 使用

- 机器与箱子相邻摆放，机器与机器、箱子与箱子可相邻连成更大的连接组；
- 原料放入连接组任意箱子，机器自动装料开始加工；成品自动放入连接组的箱子；
- 箱子满时暂停取料，腾出空间后自动继续；移动到任意地图均自动运行。

## 配置

- `Recipe` 配方表启动时自动生成，请勿手动修改。

## 卸载

删除 `Mods\Automate_v0.5.4` 文件夹即可。
