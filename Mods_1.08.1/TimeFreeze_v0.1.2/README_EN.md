# Time Freeze (TimeFreeze v0.1.2)

> [中文版](README.md)

## Features

- Press **F5** to freeze / resume the world clock.
- Only available at deep night (game display 00:00–05:59); at other times
  pressing F5 shows "Current time not available, try again at deep night"
  (shown for 1 second).
- While frozen, `TimeFreeze ON` stays at the bottom-right; press F5 again to
  resume and hide it.

> Note: don't freeze during story or time-limited quests.

## Installation

1. Close the game.
2. Put the `TimeFreeze_v0.1.2` folder into the `Mods` folder in the game root.
3. Launch the game normally from Steam (Mods are auto-loaded by the
   `steam_api64.dll` bridge).

> Only compatible with the same game version (village.exe 18,108,416 bytes).
> Mods may break after game updates.

## Uninstallation

Delete the `Mods\TimeFreeze_v0.1.2` folder.
