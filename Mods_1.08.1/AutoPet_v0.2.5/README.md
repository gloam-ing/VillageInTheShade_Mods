# 自动抚摸（AutoPet v0.2.5）

## 功能

- 每天自动抚摸所有家畜/宠物，好感 +5 × 倍率（默认每天 +5），上限 2000；
- 跨日自动重置今日已抚摸标记，无需手动操作；
- 纯数据操作 + 游戏原生事件 map，不修改游戏指令，不影响原版抚摸逻辑；
- 地址由字节签名运行时解析，游戏更新后签名失效时自动停用并写入日志。

## 安装

1. 关闭游戏；
2. 将 `AutoPet_v0.2.5` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

## 配置

配置文件 `autopet.txt`（默认自带）：`GainMultiplier=1`（1~100，好感倍率，
修改保存后实时生效；默认 1 倍，即每天 +5）。

## 卸载

删除 `Mods\AutoPet_v0.2.5` 文件夹即可。
