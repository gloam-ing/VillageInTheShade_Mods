# Birthday Reminder (BirthdayReminder v0.1.2)

> [中文版](README.md)

## Features

- Shows today's birthday villagers at the top-right of the screen every day,
  using the game's font (Resource Han Rounded TC), white, size 45, e.g.
  "Today's birthday: Kikyu".
- Hides automatically when nobody has a birthday; refreshes on a new day.

## Installation

1. Close the game.
2. Put the `BirthdayReminder_v0.1.2` folder into the `Mods` folder in the
   game root.
3. Launch the game normally from Steam (Mods are auto-loaded by the
   `steam_api64.dll` bridge).

## Uninstallation

Delete the `Mods\BirthdayReminder_v0.1.2` folder.

## Files

| File | Description |
|------|-------------|
| `birthdayreminder.dll` | The mod itself |
| `ResourceHanRoundedTC-Regular.ttf` | The game's font (loaded privately, not installed to the system) |
