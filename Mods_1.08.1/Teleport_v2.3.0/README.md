# 地图传送（Teleport Mod v2.3.0）

## 功能

- 按 **F6** 打开/关闭传送地点菜单，**PageUp / PageDown** 选择目的地，
  **[ / ]** 翻页，**Enter** 传送，**Esc** 关闭；
- **F7** 切换左上角 HUD 坐标显示，默认隐藏；
- **Alt+F6**：在小屋门口站定后手动开始定位（进档/跨日后需重新定位）；
- 手柄（完整版）：LB 开关菜单，←/→ 选择，↓ 翻页，RB 确认，A 设置页；
- 按键可在游戏内设置页修改，自动写回 `teleport.txt`；
- 目的地列表保存在 `teleport.txt`（Dest1Name/X/Y ...），可自行增删；
- 玩家坐标用 CE 式锚点收敛定位（玩家小屋门口固定坐标）；进档/跨日后由
  Alt+F6 手动触发重新收敛，不自动扫描，不依赖玩家对象虚表，游戏更新后由
  字节签名自动重定位地址；
- F7 HUD 只显示收敛副本中"随玩家移动同步变化"的活副本，不受静止副本干扰。

## 版本内四个 DLL（按设备与输入方式四选一）

| DLL | 适用 | 说明 |
|------|------|------|
| `teleport.dll` | 普通 PC | 键盘+手柄，界面固定尺寸 |
| `teleport_kbd.dll` | 普通 PC | 纯键盘，界面固定尺寸 |
| `teleport_sd.dll` | Steam Deck | 键盘+手柄，界面按屏幕自动缩放 |
| `teleport_kbd_sd.dll` | Steam Deck | 纯键盘，界面按屏幕自动缩放 |

四个 DLL 功能一致（v2.3.0），区别只在手柄支持和界面缩放。

## Steam Deck 屏幕适配

- SD 两个 DLL 按屏幕分辨率自动缩放（以 1920x1080 为基准取较小比例，上限 1.0，
  下限 0.5）；Steam Deck 原生 1280x800 自动约为 0.67，窗口与字号等比缩小；
- 需要手动固定缩放时，在 `teleport.txt` 设置 `HudScale`：0=自动，
  可设 0.4~2.0（普通 PC 两个 DLL 忽略此项）；
- Steam Deck 纯键盘可接底座/蓝牙物理键盘，或按 Steam+X 调出系统虚拟键盘。

## 安装

1. 关闭游戏；
2. 将本文件夹放入游戏根目录的 `Mods` 文件夹；
3. **从四个 DLL 中选一个使用，把其余三个删除或改名为 `.dll_bak`**
   （四个不能共存，加载器会全部加载导致按键/窗口冲突）；
4. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

## 使用与注意

- **必须到访过目的地**（默认 300 单位内）才能传送；解锁记录自动写入
  `teleport.txt` 的 `Unlock=` 行，请勿手动修改；
- 进档/跨日后需在小屋门口站定并按 **Alt+F6** 开始定位（约 1~2 秒收敛
  完成）；未定位前传送菜单不可用。定位失败（不在门口范围/定位中移动）
  不会自动重试，需再次按 Alt+F6；
- 若传送后相机没有跟着跳转、或需要移动镜头才到目标点，说明本次收敛
  地址不准确，**当日不要再使用传送，否则有闪退风险**；
- **使用前请备份存档**。

## 配置

`teleport.txt`：`Enabled`、`TeleportKey`（菜单键）、`HudKey`、`UpKey`、
`PadToggleKey` 等按键（可在游戏内修改）；`HudScale` 界面缩放（仅 SD 两个
DLL 生效）；`UnlockRadius` 到访解锁半径；
`DestNName / DestNX / DestNY` 目的地列表。

## 卸载

删除本文件夹即可。

链接附带的`teleport.txt`是预置配置，与个人按键不一定相同，自行修改
