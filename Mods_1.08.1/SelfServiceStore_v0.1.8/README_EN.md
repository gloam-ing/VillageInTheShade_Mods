# 7x11 Self-Service Store (SelfServiceStore v0.1.8)

> [中文版](README.md)

## Features

- From **07:00 to 22:59** every day, the following buildings are forced open;
  you can enter, buy and submit even when the owner is absent:
  - General Store, Lumber & Construction, Hunter Outpost, Library,
    Tea Bowl Pavilion
- **Outside that window (23:00-06:59) the mod fully passes through**,
  restoring the original game behavior.
- The **street vendor** is not included: Kianana disappears from the map
  after closing (NPC mechanism, not a door lock).

## Installation

1. Close the game.
2. Put the `SelfServiceStore_v0.1.8` folder into the `Mods` folder in the
   game root.
3. Launch the game normally from Steam (Mods are auto-loaded by the
   `steam_api64.dll` bridge).

> Only compatible with the same game version (village.exe 18,108,416 bytes).
> Mods may break after game updates.

## Uninstallation

Delete the `Mods\SelfServiceStore_v0.1.8` folder.
