# 7x11自助商店（SelfServiceStore v0.1.8）



## 功能

- 每天 **07:00–22:59** 以下建筑强制开门，店主不在时也可进入/自助购买/提交：
  - 杂货店、树木建设、猎人哨站、图书馆、料理屋
- **其余时段（23:00–06:59）完全放行**，恢复游戏原版行为。
- 不包含**街边小贩**：琪娜娜收摊后会从地图消失（NPC 机制，非门锁）。

## 安装

1. 关闭游戏；
2. 将 `SelfServiceStore_v0.1.8` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

> 只适配相同游戏版本（village.exe 18,108,416 字节）。游戏更新后本 Mod 可能失效。

## 卸载

删除 `Mods\SelfServiceStore_v0.1.8` 文件夹即可。
