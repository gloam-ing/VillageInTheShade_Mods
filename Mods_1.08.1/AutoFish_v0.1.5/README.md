# 自动钓鱼（AutoFish v0.1.5）



## 功能

- 自动完成钓鱼全过程：咬钩自动起竿、自动完成音符小游戏、收竿后自动续竿连续钓鱼；
- 可选的垃圾排除：开启后钓鱼不再获得四种垃圾（空罐/塑料袋/水草/树枝），只出鱼；
- 零按键模拟：通过游戏原生字节补丁与状态机钩子实现，不注入按键，不影响键盘/手柄输入；
- 地址自动解析：启动时用字节签名定位游戏内部函数，游戏更新后签名失效时自动停用并写入日志，不会崩溃。

## 安装

1. 关闭游戏；
2. 将 `AutoFish_v0.1.5` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

> 只适配相同游戏版本（village.exe 18,105,864 字节）。游戏更新后本 Mod 可能失效。

## 使用

- 装备鱼竿，在任意钓鱼点抛竿即可；钓鱼小游戏仍会显示，由 Mod 自动完成；
- 无需配置文件，自动钓鱼默认开启；
- 垃圾排除默认关闭，按 **F10** 切换开关（仅键盘，不接手柄）；开启后日志记录
  一行 `no-trash ON`，关闭时记录 `no-trash OFF (exec/skip)` 统计；
  切换时屏幕右下角显示 1.8 秒提醒（已开启/已关闭）。

## 卸载

删除 `Mods\AutoFish_v0.1.5` 文件夹即可。
