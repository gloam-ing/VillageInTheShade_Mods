# 下矿助手（Mine Helper v1.1.1）



## 功能

- 让你能够在高层石头非常多的情况下也能保证最多敲15块就找到矿洞；
- `FirstHole=1`：配置支持，第一块石头就出洞，默认关闭，谨慎开启。

## 安装

1. 关闭游戏；
2. 将 `MineHelper_v1.1.1` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 正常从 Steam 启动游戏即可（Mods 由 steam_api64 桥接基座自动加载）。

## 卸载

直接删除 `MineHelper_v1.1.1` 文件夹即可。

## 配置（minehelper.txt）

| 配置 | 说明 |
|------|------|
| `FirstHole` | 1 = 第一块石头出洞；0 = 默认 |

修改保存后立即生效（下一层起）。

## 文件

| 文件 | 说明 |
|------|------|
| `minehelper.dll` | Mod 本体 |
| `minehelper.txt` | 配置（FirstHole / F9 切换） |
