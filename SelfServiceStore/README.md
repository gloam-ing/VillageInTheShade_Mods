# 24小时自助商店（SelfServiceStore v0.1.3）

> [English](README_EN.md)

## 功能

- 以下建筑**全天营业**，不受打烊时间限制，店主不在时也可进入/自助购买：
  - 杂货店（9:00~17:00，周五公休）
  - 树木建设（10:00~17:00，周六日公休）
  - 猎人哨站（10:00~17:00，周一/二公休）
  - 图书馆（9:00~17:00，周六日公休）
  
- **茶碗亭**：门可全天进入；点餐仍按游戏原逻辑，

  受营业时间限制（11:00~22:00，周四/五公休），暂不处理。

- 不包含**街边小贩**：琪娜娜收摊后会从地图消失（NPC 机制，非门锁），
  不在本 mod 覆盖范围。

## 安装

1. 关闭游戏；
2. 将 `SelfServiceStore_v0.1.3` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 通过 `VillageModLoader.exe` 启动游戏（设为 Steam 启动项）。

> 只适配相同游戏版本（village.exe 18,108,416 字节）。游戏更新后本 Mod 可能失效。

## 卸载

删除 `Mods\SelfServiceStore_v0.1.3` 文件夹即可。
