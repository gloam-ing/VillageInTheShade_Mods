# One-Shot Hunt (HuntOneShot v0.1.1)

> [中文版](README.md)

## Features

- All wild animals (squirrels, boars, rabbits, deer, etc.) can be hunted
  successfully with **a single shot**; no more multiple hits.
- Does not affect drops or hunting settlement; animals still flee/disappear
  normally.

## Installation

1. Close the game.
2. Put the `HuntOneShot` folder into the `Mods` folder in the game root.
3. Launch the game via `VillageModLoader.exe` (set it as a Steam launch option).

> Only compatible with the same game version (village.exe 18,108,416 bytes).
> Mods may break after game updates.

## Uninstallation

Delete the `Mods\HuntOneShot` folder.
