# 狩猎一击必杀（HuntOneShot v0.1.1）

> [English](README_EN.md)

## 功能

- 所有野生动物（松鼠、野猪、兔子、鹿等）**一枪即可狩猎成功**，
  不需要再打多枪。
- 不影响掉落物与狩猎结算，动物仍会正常逃跑/消失。

## 安装

1. 关闭游戏；
2. 将 `HuntOneShot_v0.1.0` 文件夹放入游戏根目录的 `Mods` 文件夹；
3. 通过 `VillageModLoader.exe` 启动游戏（设为 Steam 启动项）。

> 只适配相同游戏版本（village.exe 18,108,416 字节）。游戏更新后本 Mod 可能失效。

## 卸载

删除 `Mods\HuntOneShot_v0.1.0` 文件夹即可。
